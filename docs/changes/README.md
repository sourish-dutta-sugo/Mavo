# docs/changes/

> Last updated: 2026-09-29

This directory stores change reports generated after completing tasks.

Each task report follows the naming convention specified in [CHANGE_REPORT_GUIDE.md](../agent-rules/CHANGE_REPORT_GUIDE.md):
`YYYY-MM-DD_vX.X.X.X_short-title.md` (or `YYYY-MM-DD_vX.X.X_short-title.md`)

Reports are ordered chronologically by date (newest first).
